## Rules
- Inspect the repository first.
- Preserve routes, backend data, authorization, validation, audit, publication controls, and result authority.
- Use actual PMMS data.
- Do not hardcode screenshot values.
- Do not use screenshots as backgrounds.
- Live scores remain provisional; finalized results remain authoritative.
- Municipality is the official delegation; school is the athlete's origin.
- Use Laravel, React, Inertia, TypeScript, Tailwind CSS 4, and shadcn/ui.
- Support phone, tablet, desktop, TV, projector, LED wall, and kiosk where applicable.
- Respect reduced-motion preferences.
- Run all quality checks.
- Update documentation.
- Do not commit or push.
- Do not begin the next work package.

## Exclusions
No Flutter, AI prediction, SaaS, Regional/National implementation, proprietary broadcast hardware, sponsor billing, or unrelated backend redesign.


## Objective
Create a premium public portal hero and event entry experience using real meet data, live-now entry, current leaders, upcoming events, latest official result, announcement strip, and responsive branding.

## Acceptance Criteria

- Actual PMMS data is used.
- Visual work is responsive and accessible.
- Reduced-motion behavior works.
- Live-score authority is preserved.
- Large-display views exclude private data.
- Tests and quality checks are complete.
- Documentation is updated.
- No unrelated features are added.
- No commit or push is performed.
