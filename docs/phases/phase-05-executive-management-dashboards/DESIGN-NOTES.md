# Phase 5 Design Notes

## Official Provincial Meet aggregation

```text
Municipality = Delegation
School = Athlete’s Origin Institution
```

Use delegation for:

- Official medal tally
- Delegation ranking
- Delegation participation
- Meet-level comparison

Use school origin for:

- School contribution
- Athlete origin
- School participation
- Internal performance review

## Dashboard style

- Simple summary cards
- Clear tables
- Limited charts
- Mobile-responsive layout
- Role-based access
- No fake data
- No AI recommendations
