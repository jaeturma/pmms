# TWG roles

TWGs reuse `management_teams` and `management_team_members`. `source_code` gives each workbook unit a stable identity while `role_title` preserves the source designation. A pre-account member references `person_id`; after invitation activation the same membership may also reference `user_id`.

The import includes 25 units and 144 memberships. People may belong to multiple units. No committee-specific tables are created. The detailed responsibility wording is sourced from `docs/final/TWG_ROLE_MATRIX.md` and stored as each team's description.

Operational authorization remains capability-specific: DSAC, Medical, Results, ICT, logistics, and other workflows do not derive approval authority merely from a free-text TWG title.
