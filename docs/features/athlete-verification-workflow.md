# Athlete verification workflow

An approved Coach may register athletes only within the Coach's approved delegation, sport, and event scope. Athlete registration is accepted even when verification attachments are incomplete.

Every registered athlete immediately receives a pending eligibility review containing this five-item checklist:

1. Athlete History
2. Form 10
3. PSA / Birth Certificate
4. Parents Consent
5. Medical Certificate

Missing files appear as **Missing / For submission**. Uploading files does not qualify an athlete automatically. Authorized DSAC members validate individual documents; DSAC leadership may return the review as **Incomplete / For Submission**, reject it, or manually mark the athlete **Qualified**. Qualification is available only when all five required types have a validated current document.

Tournament Manager, Technical Official, Tournament ICT, and Tournament Secretary assignments receive read-only athlete and eligibility visibility limited to their assigned sports. These roles cannot make the DSAC qualification decision.
